Sheet Magic 隐私政策

最后更新：2026年1月17日

摘要：Sheet Magic 不会向外部服务器收集、保存或传输个人数据，所有处理都在浏览器中完成。

1. 我们不收集的信息

我们不收集个人身份信息、Google Sheets 内容、生成的 PDF/PPT、使用统计或浏览记录。

2. 工作方式

通过 Google Sheets API 读取数据，通过 Google Slides API 生成文件。文件保存到 Google Drive 或下载到电脑。

3. 权限说明

权限用于 Google OAuth、检测当前表格、读取页面信息、保存设置和下载文件。

4. 数据存储

字体、模板、工作配置和预约信息通过 Chrome storage API 保存在本地设备。

5. Google 服务

使用 Google Sheets、Slides 和 Drive API。请参阅 Google 隐私政策。

6. 数据安全

与 Google API 的通信使用 HTTPS 加密，数据不会发送到我们的服务器。

7. 儿童隐私

我们不会故意收集 13 岁以下儿童的信息。

8. 政策变更

政策变更会发布在本页面，并更新日期。

9. 联系方式

联系邮箱：sheetmagic@pocketwork.org

10. 您的权利

您可以卸载扩展程序、在 Google 账户中撤销 API 权限，并清除本地设置。
