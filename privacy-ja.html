Sheet Magic プライバシーポリシー

最終更新日：2026年1月17日

概要：Sheet Magic は個人データを外部サーバーに収集・保存・送信しません。処理はブラウザ内で行われます。

1. 収集しない情報

個人情報、Google Sheets の内容、生成したファイル、利用統計、閲覧履歴を収集しません。

2. 動作方法

Google Sheets API でデータを読み取り、Google Slides API でファイルを生成します。ファイルは Google Drive に保存するか、端末にダウンロードします。

3. 権限

Google OAuth、現在のシートの検出、ページ情報の読み取り、設定の保存、ファイルのダウンロードに必要な権限を使用します。

4. データ保存

フォント、テンプレート、プロフィール、予約などの設定は Chrome の storage API に端末内で保存されます。

5. Google サービス

Google Sheets、Slides、Drive API を利用します。詳細は Google のプライバシーポリシーをご覧ください。

6. セキュリティ

Google API との通信は HTTPS で保護され、当社のサーバーへデータを送信しません。

7. 子どものプライバシー

13歳未満の子どもから意図的に情報を収集しません。

8. 改定

変更がある場合はこのページに掲載し、更新日を変更します。

9. お問い合わせ

お問い合わせ：sheetmagic@pocketwork.org

10. 利用者の権利

拡張機能のアンインストール、Google アカウントからの API アクセス取消し、保存設定の削除ができます。
