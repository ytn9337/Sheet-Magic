Sheet Magic

Google Sheets의 데이터를 Google Slides 템플릿에 채워 PDF 또는 PPT로 만들어주는 Chrome 확장프로그램입니다.

빠른 시작

처음에는 아래 순서대로 한 번만 설정하면 됩니다.

01 · 시트 연결

Google Sheet를 연 상태에서 시작

확장프로그램을 열고 현재 시트가 연결되었는지 확인합니다. 헤더를 불러온 뒤 행 범위와 필요한 폰트를 설정합니다.

02 · 템플릿 선택

Google Drive에서 Slides 양식 선택

값을 채울 Google Slides 템플릿을 선택합니다. 선택한 템플릿은 작업 프로필에도 저장할 수 있습니다.

03 · 반복 작업 저장

작업 프로필로 설정 재사용

행 범위, 필터, 그룹핑, 폰트, 출력 방식을 하나의 프로필로 저장합니다. 다음 작업에서는 프로필을 불러오기만 하면 됩니다.

04 · 자동 실행

원하는 시간에 예약 생성

저장된 프로필과 실행 주기를 선택하고 예약합니다. 실행 결과와 실패 원인은 예약 관리 화면에서 확인할 수 있습니다.

Slides 템플릿 작성법

시트의 헤더 이름을 이중 꺾쇠로 감싸면 해당 열의 값이 들어갑니다.

<<헤더>>
<<상수도{날짜:2025-02-09}>>

첫 번째 형식은 일반적인 값 치환에 사용합니다. 두 번째 형식은 한 페이지 안에서 특정 조건에 맞는 값을 골라 넣을 때 사용합니다. 헤더 이름은 Google Sheet의 첫 번째 행과 정확히 일치해야 합니다.

팁
템플릿을 먼저 소수의 행으로 테스트한 뒤 전체 행을 생성하면 API 쿼터와 결과 오류를 줄일 수 있습니다.

작업 프로필

반복해서 사용하는 작업은 작업 생성 탭에서 설정을 저장하세요. 프로필에는 템플릿, 행 범위, 필터, 그룹 기준, 폰트, 출력 방식과 저장 위치가 함께 기록됩니다.

프로필을 불러온 뒤에는 현재 화면의 값이 바뀌었는지 확인하고 생성하면 됩니다. 초기화 버튼은 프로필과 예약을 삭제하지 않고 일반 설정만 초기화합니다.

예약 생성

예약 관리 탭에서 프로필, 실행 주기, 시간을 선택합니다. 결과 저장 위치도 Google Drive와 컴퓨터 다운로드 중에서 지정할 수 있습니다.

  1. 작업 생성 탭에서 프로필을 저장합니다.
  2. 예약 관리 탭에서 프로필과 시간을 선택합니다.
  3. 저장 위치를 선택하고 예약 저장을 누릅니다.
  4. 최근 실행 결과, 실패 원인, 재시도 시간과 결과 링크를 확인합니다.
주의
예약 생성은 Chrome 확장프로그램의 백그라운드 알람을 사용합니다. Google Slides API의 사용량 제한에 걸리면 자동 재시도될 수 있습니다.
