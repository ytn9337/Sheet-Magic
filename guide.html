Sheet Magic

Google Sheets의 데이터를 Google Slides 템플릿에 자동으로 넣어 PDF 또는 PPT로 만드는 Chrome 확장프로그램입니다.

빠른 시작

01 · 시트 연결

Google Sheets 열기

대상 시트를 열고 헤더를 불러온 뒤 사용할 범위와 폰트를 설정합니다.

02 · 템플릿

Google Slides 양식 선택

치환 태그가 들어 있는 Google Slides 파일을 선택합니다.

03 · 작업 프로필

설정 저장 및 재사용

폰트, 범위, 출력 설정을 프로필로 저장해 다음 작업에서 불러옵니다.

04 · 예약 생성

자동 생성 예약

프로필, 실행 시간, 저장 위치를 지정해 자동 생성을 예약합니다.

템플릿 작성

시트 헤더 이름을 이중 꺾쇠 안에 입력합니다.

<<헤더>>
<<WaterSupply{Date:2025-02-09}>>

일치하는 태그가 시트의 값으로 치환됩니다.

작업 프로필

템플릿, 범위, 폰트, 출력 형식과 저장 위치를 하나의 프로필로 저장할 수 있습니다.

예약 생성

저장한 프로필과 실행 시간을 선택합니다. 결과와 오류는 예약 관리에서 확인할 수 있습니다.
