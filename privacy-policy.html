Privacy Policy for Sheet Magic

Last Updated: January 17, 2026

Summary: Sheet Magic does not collect, store, or transmit any of your personal data to external servers. All data processing happens locally in your browser.

1. Information We Do NOT Collect

Sheet Magic does not collect, store, or transmit any of the following:

  • Personal identification information
  • Google Sheets data content
  • Generated PDF or PPT files
  • Usage statistics or analytics
  • Browsing history

2. How Sheet Magic Works

Sheet Magic operates entirely within your browser:

  • Data Reading: Reads data from your Google Sheets using Google Sheets API
  • File Generation: Creates PDF/PPT files using Google Slides API
  • File Storage: Saves files directly to your Google Drive or downloads to your computer
  • Local Processing: All data processing happens in your browser - nothing is sent to our servers

3. Permissions Explained

Sheet Magic requests the following permissions:

  • identity: For Google OAuth authentication to access Google APIs
  • activeTab: To detect the current Google Sheets page
  • scripting: To extract sheet information from Google Sheets pages
  • storage: To save your preferences (font settings, templates) locally in your browser
  • downloads: To download generated PDF files to your computer
  • Google API access: To read Google Sheets data and create files in Google Drive/Slides

4. Data Storage

The only data stored by Sheet Magic is:

  • User Preferences: Font settings, template selections, and other configuration options
  • Storage Location: Stored locally in your browser using Chrome's storage API
  • Access: Only accessible by the extension on your device

5. Third-Party Services

Sheet Magic interacts with Google services:

  • Google Sheets API: To read spreadsheet data
  • Google Slides API: To create presentations
  • Google Drive API: To save generated files

These interactions are governed by Google's Privacy Policy.

6. Data Security

  • All communication with Google APIs uses HTTPS encryption
  • OAuth tokens are managed securely by Chrome's identity API
  • No data is transmitted to third-party servers

7. Children's Privacy

Sheet Magic does not knowingly collect any information from children under 13. The extension is designed for general productivity use.

8. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last Updated" date.

9. Contact Information

If you have any questions about this Privacy Policy, please contact us through the Chrome Web Store support page.

10. Your Rights

You have the right to:

  • Uninstall the extension at any time
  • Revoke Google API access through your Google Account settings
  • Clear stored preferences by removing the extension
