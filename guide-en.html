Sheet Magic

Fill Google Slides templates with Google Sheets data and generate PDF or PPT files from Chrome.

Quick start

Set up the workflow once, then reuse it whenever you need to generate documents.

01 · CONNECT

Open a Google Sheet

Open the extension while a Google Sheet is active. Confirm the connection, load the headers, and set the row range and font sizes.

02 · TEMPLATE

Select a Slides template

Choose the Google Slides file that contains the layout you want to fill. The selected template can be saved in a task profile.

03 · REUSE

Save a task profile

Save the row range, filters, grouping, fonts, output mode, and destination together. Load the profile next time instead of entering everything again.

04 · AUTOMATE

Schedule a generation

Select a saved profile, choose a frequency and destination, and review the latest result or retry status in Schedule Management.

Writing a Slides template

Wrap a Sheet header in double angle brackets to insert the value from that column.

<<Header>>
<<WaterSupply{Date:2025-02-09}>>

The first form inserts a value directly. The conditional form selects a value from the row that matches the condition. Header names must match the first row of the Sheet.

Tip
Test a small row range before generating a large batch. This makes template errors and API quota issues easier to identify.

Task profiles

Save recurring work in the Generation tab. A profile stores the template, row range, filters, grouping, fonts, output mode, and destination.

After loading a profile, confirm the visible settings before generating. Reset clears ordinary settings but preserves saved profiles and schedules.

Scheduled generation

In Schedule Management, select a profile, frequency, time, and destination.

  1. Save a profile in the Generation tab.
  2. Select the profile and time in Schedule Management.
  3. Choose Google Drive or local download.
  4. Review the latest result, failure reason, retry time, or output link.
Note
Scheduled generation uses the Chrome extension alarm system. Temporary Google Slides API quota limits may cause an automatic retry.
